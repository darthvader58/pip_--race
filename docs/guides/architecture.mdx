## Language Responsibilities

- **Python**: public API, feature orchestration, notebooks, data products, visualization specs.
- **PyTorch**: model development and ONNX export.
- **C++**: native low-level scoring/preprocessing kernels.
- **Go**: parallel JSONL replay and batch scoring workers.
- **Rust**: low-latency timing sidecars and async service integration.
- **Linux**: target production deployment for CPU pinning, predictable scheduling, and colocated services.
